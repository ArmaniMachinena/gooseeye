# GooseEye — гусь видит?

Проверка маскировки окопа на гуся по фото. Напарник снимает окоп сверху, приложение ищет блики, светлую кожу, тёмную «дыру», несовпадение цвета и фактуры со стернёй, учитывает вид гуся, время, свет, сезон, ветер и давление охоты — и выдаёт «заметит / не заметит» в процентах со списком того, что исправить.

- Работает без интернета: открыть один раз в Safari → «Поделиться» → «На экран Домой».
- Фото никуда не отправляются, всё считается на телефоне.
- Проценты — модель на основе советов охотников и данных о зрении птиц, не измерение. Журнал охот помогает их уточнять.
- Пискулька и краснозобая казарка — охраняемые виды, охота на них запрещена.
